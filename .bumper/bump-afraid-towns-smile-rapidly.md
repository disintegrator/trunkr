Add the interactive worktree picker: a keybindable overlay listing every worktree with its live pane count, rolled-up agent status (worst-first: blocked > working > done > idle), and git state. Enter switches (focusing existing panes), t/w/s open in a new tab/workspace/split, c creates a branch, p checks out a PR, / filters, and keys are remappable via [picker.keys].
